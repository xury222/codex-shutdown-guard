# Codex 关机守卫

Windows 本地 Codex 任务监控、账户额度面板与任务完成后关机工具。原生托盘程序负责监控和关机判断，聊天插件提供状态查询与控制入口。

- 由主任务决定是否等待；子代理和内部审批保留在列表中，不单独阻止关机。
- 文件已移除且没有已观测未结束回合的历史读取占位会自动清理，避免长期阻塞。
- 显示账户额度窗口、剩余额度及重置时间。
- 明确开启自动关机后，等待本机主任务完成并进入可撤销的倒计时。
- 使用当前系统代理启动 Codex，并分别设置守卫启动时启动 Codex、启动 Codex 时启动守卫。

功能只覆盖本机 Codex 桌面任务。项目通过 GitHub 分发，尚未上架 OpenAI 官方插件目录。

## 双击安装

1. 在 [1.1.3 Release](https://github.com/xury222/codex-shutdown-guard/releases/tag/v1.1.3) 下载 `codex-shutdown-guard-windows-1.1.3.zip`，右键选择“全部解压”。
2. 打开解压后的文件夹，双击根目录的 `Install.cmd`，在窗口中点击“安装并启动”。

完成后，可从桌面快捷方式或系统托盘打开守卫。

默认安装原生守卫，无需输入命令，也不需要 Node.js 或 Codex CLI。原生程序使用系统 Windows PowerShell 5.1。新安装位于当前用户的 `%LOCALAPPDATA%\Programs\CodexShutdownGuard`，会创建桌面和当前用户登录启动快捷方式；已有有效注册或带产品标记的旧安装会继续复用。

安装不会开启自动关机。守卫启动后默认未布防，只有手动勾选托盘中的“任务完成后自动关机”，才会在任务完成和倒计时结束后请求 Windows 关机。更新会保留已有配置；守卫已布防时须先取消自动关机，再重新安装。

完整仓库源码也可使用同一入口。普通用户优先选择 Windows 包；单插件 ZIP 不包含根目录的双击安装窗口。详细步骤、卸载和手动安装方式见 [安装说明](docs/INSTALL.md)。

## 聊天插件（可选）

需要在聊天中查看状态或控制守卫时，勾选安装窗口中的“同时安装 / 更新 Codex 聊天插件（可选，需联网）”，再点击“安装并启动”。窗口会在后台执行插件安装命令，并显示完成或失败原因。

聊天插件需要 Node.js 18 或更新版本、支持插件命令的 Codex CLI，以及 Git。安装窗口会检测这些程序，也会寻找 Codex 桌面应用自带的 CLI；缺少依赖时，聊天插件选项不可选，原生守卫仍可安装。窗口提供官网下载入口，不会自动下载或安装依赖。补齐后关闭并重新打开安装窗口即可重新检测；Node.js 建议选择官网 LTS 版本。

通过窗口安装的聊天插件使用 GitHub 固定版本 `v1.1.3`，安装后无需保留下载的解压目录。完成后关闭并重新打开 Codex，以刷新插件工具；安装器不会自动重启 Codex。已有停用的聊天插件不会被安装器自动启用。

可以请求“查看关机守卫状态和账户额度”“显示关机守卫面板”“取消自动关机”“启动 Codex 时自动启动守卫”。完整的 9 个工具见 [插件说明](plugins/codex-shutdown-guard/README.md)。启用聊天插件本身不会安装原生程序或开启自动关机。

## 卸载与反馈

双击完整 Windows 包根目录的 `Uninstall.cmd`，在窗口中点击“卸载守卫”。卸载会移除属于本安装的程序文件及快捷方式，保留状态目录和额外文件。聊天插件可在 Codex 插件管理中单独移除。

[版本说明](RELEASE_NOTES.md) 记录 1.1.3 的历史读取占位清理及历史版本变化；本轮检查范围见 [验证记录](VALIDATION.md)。从源码打包时，在仓库根目录运行 `python scripts/build-release.py`，产物写入 `dist`。源码清单为 `SOURCE_SHA256SUMS.txt`，Release 附件 `SHA256SUMS.txt` 用于校验两份 ZIP。

问题反馈请提交到 [Issues](https://github.com/xury222/codex-shutdown-guard/issues)，并提供版本、Windows 环境、操作步骤及必要的已脱敏日志。公开附件不要包含账户凭据、私人会话或用户配置。
